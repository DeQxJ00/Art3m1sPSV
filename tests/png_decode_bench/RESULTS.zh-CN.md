# PSV PNG 解码对比结果（2026-09-10）

结论：libpng 对本次真实 RGBA32 样本较快，对 PAL8 的收益取决于素材，不能据此全量替换现有 Rust 解码器。当前游戏仍使用原解码路线；本次只运行独立探针，未改 shader、调度或缓存额度。

## 主结果

实体机 333MHz CPU / 222MHz bus / 111MHz GPU；每个样本、每个解码器各10次，交替顺序。表中为解码到 CPU RGBA 的中位数，包含输出分配和转换，不含读盘、输出释放、比较像素、日志写入。

| 样本 | 尺寸 | Rust / ms | libpng / ms | libpng 耗时降低 |
|---|---:|---:|---:|---:|
| 真实背景 / PAL8 | 1920×1080 | 285.296 | 270.752 | 5.1% |
| 真实立绘 / PAL8 | 984×993 | 73.706 | 80.296 | -8.9% |
| 真实立绘 / RGBA32 | 618×597 | 98.722 | 89.281 | 9.6% |
| 合成大图 / PAL8+tRNS | 960×540 | 62.000 | 62.568 | -0.9% |
| 合成图 / RGBA32 | 641×257 | 127.442 | 74.400 | 41.6% |
| 小图 / PAL8 不透明 | 19×17 | 0.352 | 0.278 | 21.3% |
| 小图 / PAL8+tRNS | 19×17 | 0.286 | 0.238 | 16.6% |
| 合成图 / RGBA 每通道16位 | 67×39 | 4.702 | 3.736 | 20.5% |

负数表示 libpng 更慢。所有8个样本均逐字节比较 RGBA 一致，160次计时解码全部成功；包括256色索引、部分 tRNS 及透明度边界。此结果覆盖选定样本，不代表所有 PNG 变体都已验证。RGBA32 指每通道8位；最后一项每通道16位，共64位/像素，转换输出仍为 RGBA8。

## 内存与性能含义

独立跟踪轮记录输出及解码器申请的存活字节峰值：

| 真实素材 | Rust / bytes | libpng / bytes |
|---|---:|---:|
| 真实背景 / PAL8 | 8579680 | 8362078 |
| 真实立绘 / PAL8 | 4184131 | 3968892 |
| 真实立绘 / RGBA32 | 1758434 | 1530275 |

上述值不含压缩输入、分配器头/对齐、栈及部分记账对象，不是整个进程峰值，也不是最大连续空闲块。两者均包含最终 CPU RGBA 输出；本次没有直接解码到 CDRAM、GPU 上传、缓存命中和游戏音频/渲染负载。不能将解码耗时降幅等同为 FPS 提升，也不能用它证明96MiB缓存安全。

真实 PAL8 背景仅改善约5%，PAL8立绘反而慢约9%；只按 PAL8/RGBA 分类选择解码器还缺少广泛素材证据。真实 RGBA32 改善约10%，远小于合成样本约42%的收益，不能只引用合成结果。

## 运行有效性和恢复

主结果来自 `20260910-075113`，带可见进度条。日志确认显示初始化成功、自动休眠锁和 OLED 锁均返回0，完成标记为 `DONE failures=0`。进度条使用2.25MiB独立CDRAM显示缓冲，更新和电源tick位于计时间隔之外；两种解码器在同一显示条件下比较。自动休眠锁不保证手动切后台不影响结果。

`20260910-074149` 和 `20260910-074801` 两轮经用户确认进入休眠/后台，全部耗时作废，即便后一轮写出了DONE。对应本地manifest已标记 `performance_valid=false`，汇总脚本拒绝处理。早期无显示的完整7样本运行 `20260910-073922` 只用于核对收益方向，不合并绝对耗时。

本轮恢复时遇到FTP临时550错误；随后重新上传原始备份，读回比对一致并启动游戏。原程序 SHA256：`1fe6a176a6236861c603ccc8796de32be0acbd4f4260058a96f2f2cbd5baa94a`。这仍是 shared-decode-252cf26 候选，不改变 stable latest 指向。

- 继续按统一内存账本与准入 → 未发布最终纹理存储 → 后台按行写入 → 渲染线程发布/GPU结束后回收的顺序推进。原生libpng按行写Surface的方案值得验证；本轮没有证明直接写GPU存储一定更快。
- 暂不全量接入libpng或仅凭PNG格式设置分流，不扩到96MiB。下一阶段比较整条加载路径与首次/重复切场景长帧，并完成OGV进出和快进稳定性验收。
