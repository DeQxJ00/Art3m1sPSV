# 单通道字体图集验证（2026-09-20）

Direct GXM 的正文、姓名、Backlog 共用 GlyphTextRenderer。Vita 图集保持
512×512，CPU 持久图集只保存 Alpha，GPU 使用 U8_R111，采样恢复为
白色 RGB＋覆盖率 Alpha。字体、字号、布局、描边算法、阴影、着色参数不变。
菜单独立字体图集及 RGBA 离屏目标不在本次范围内；桌面后端保持原格式。

新增字形只上传合并后的脏矩形；失败保留待上传区域，成功才更新纹理版本。
GPU 上传不另留 CPU 像素副本。启动格式自检失败时使用 RGBA 上传回退。
字形栅格化的短期 RGBA 缓冲仍保留，本次压缩的是持久图集。

## 实机字体对照

本地指定字体制作独立场景，不把商业字体提交仓库：

```text
python tests/font_alpha/prepare.py --font <本地字体路径>
```

三个页面覆盖 0/0.5/1/2 像素描边、彩色文字、阴影、不同字号、新字形局部
更新以及重新显示旧字形。截图使用原始 960×544 PNG，排除右侧动态缓存 HUD
矩形 [650,0,960,250]，其余区域全部比较。

```text
python tests/font_alpha/compare.py build/font-alpha/device --max-delta 4
python tests/font_alpha/compare.py build/font-alpha/device --candidate baseline-repeat --max-delta 4
```

比较脚本默认容差为 0，必须显式指定本轮接受的容差 4（8 位通道）。
本轮不宣称真实字体截图逐像素一致：

| 页面 | 新旧最大通道差 | 新旧不同像素 | 旧版重启最大通道差 | 旧版重启不同像素 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 4 | 690 | 3 | 780 |
| 1 | 3 | 1677 | 3 | 1398 |
| 2 | 3 | 178 | 2 | 79 |

差异集中在描边，未发现缺字或布局变化。原有描边分配遍历 HashSet，重启后
图集布局可能不同，这是轻微采样差异的可能来源，尚未单独证明全部差异的原因。
用户已接受本轮轻微色差；不能据此声称字体画面完全一致或游戏帧率已提高。

同一独立场景有一页图集，实机账本测得：

| 项目 | RGBA 基线 | Alpha 测试版 | 减少 |

每页 CPU 和 GPU 图集分别从 1 MiB 降至 256 KiB，合计节省 1.5 MiB。
未扩大缓存额度、修改频率或降低字形分辨率。
