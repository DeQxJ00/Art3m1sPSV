# 字体描边毛边修正（2026-09-20）

## 原因与范围

otomeriron 的 `system/table/list_windows_tw.tbl` 正文配置为 size=24、outline=2、
color=ffffdd、outlinecolor=512f40（本地只读资源副本
`build/otomeriron-logo-ui/current/`）。旧 glyph.rs 仅在四个对角位置各画一次字形，
并非连续轮廓；2px 描边的细小笔画会出现凸起、空隙和抗锯齿重叠加深。
图集初始空白 RGB=0、alpha=0，与白色字形覆盖率一起线性采样还会使边缘变暗。

核心提交 `0f4897a`，基于 `ac788cd`；可重放补丁
`patches/font-outline-cache-core.patch`。没有游戏名特判，不改资源、字号、排版、
游戏 shader、缓存共享池或 MP4 修复。

- 将覆盖率作圆形邻域的最大值扩张，边界使用分数覆盖率，再以单个描边 quad 绘制。
  属于栅格描边近似，并非原生字体引擎的矢量 stroker 像素级复刻。
- 按不可变字形图集区域和 1/16px 描边宽度缓存，正文、姓名、历史文字共用。
  0<宽度<=16px 且可放入图集时走新路径，异常大宽度/区域保留旧绘制回退。
- 描边跟随字身的透明度、旋转及缩放，颜色不烘入缓存，链接换色不用重新生成。
- 在绘制前的纹理准备阶段生成、上传；快照版本未变化时跳过扫描。
  普通带描边字形由四层描边加字身的 5 个 quad 降为 2 个。
- 透明图集空白设为白 RGB/零 alpha，普通字形四侧留透明间隔。
  字形度量和 UV 有效尺寸不变；保留原最大字形尺寸支持。

新增描边会占用现有字体图集空间；不是无内存成本。仍沿用每页 512² RGBA
及原字体账本/生命周期。本次六行测试前后均只用一页，不能据此声称所有游戏
都不增加页数。未修改现有注音样式功能范围。

## 验证

- 504 项核心测试通过，18 项需外部条件的测试忽略。
- 指定游戏实际 `sourcehansanssc-bold.otf`，70 项文字测试全部通过，包含
  覆盖率对称性/连续性、分数宽度、图集复用、预上传、2 quad 数量、描边关闭、
  宽度变更失效、字号覆盖恢复及逐字进度/排版保留。
- Vita 核心、宿主构建成功。现有构建时钟偏差警告仍在，部署回读已核对新 SELF。
- 实机 333MHz/ES4 111MHz，同字体同文字，24/32px、0/0.5/1/2px 描边前后截屏。
  修正版轮廓明显更连贯；固定测试页面保持约60帧。该页面有静态合成复用，
  不能把它当作实际剧情换句耗时或所有场景帧率的验收。
- 无描边行也有332个变化像素，来自图集透明留白的采样修正；没有声明全图相同。
  原始字号、文字度量与排版不变由核心测试验证。
