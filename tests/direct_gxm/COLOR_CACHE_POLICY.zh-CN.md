# 色调效果的缓存策略

灰度、颜色乘算和 sepia 通过原始 shader 内容校验获得逐像素色调能力，统一使用已有的结果、输入和移动缓存。脚本给效果起的名字不构成能力证明；未知 shader 保留完整的屏幕空间依赖检查。

| 变化 | 处理 |
| --- | --- |
| 输入、参数及变换都不变 | 复用最终结果 |
| 仅效果参数改变，输入不变 | 复用输入，重新执行原 shader |
| 整组平移、采样相位不变 | 在缓存覆盖范围内复用移动结果 |
| 半像素等采样相位变化 | 保留原渲染路径，避免对已量化的色调结果再次插值 |
| 缩放、源图内容、局部层位置或颜色变化 | 缓存失效；稳定后重新准入 |
| mask、用户纹理、非单位效果 alpha 或未验证效果 | 保留原隔离及依赖检查 |

颜色乘算和 sepia 还要求 RGB 参数明确且在 `[0,1]` 内。带加性偏移的效果不自动获得这一能力。原 shader、RGBA8 中间结果和图层混合顺序不变；连续缩放不通过忽略变换来强行命中缓存。已证明中性的父分组可以省去冗余合成，原色调 pass 仍执行。

移动结果沿用现有的一组有界缓存、内容与 shader 修订号、稳定观察准入、显存压力退出和 GPU 资源生命周期。单张背景和多层组合采用同一套能力规则，不按场景配置缓存。

## 验证

- Rust 原生效果测试 69 项通过，包含三类色调的单层/多层准入、未知来源拒绝、用户纹理/alpha 拒绝和 shader 替换撤销能力。
- C++ 缓存测试通过，包括 1185 项坐标及失效检查，以及新增的整数/亚像素相位检查。
- 实机探针已扩展为灰度、颜色乘算、sepia，并比较原路径与缓存路径；覆盖透明层、整数移动、亚像素回退及资源/参数失效。
